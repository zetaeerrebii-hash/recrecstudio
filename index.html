The "IN n" menu on each track picks which physical input feeds it — CH1→Track1 in order by default, reassign it if your mixer's patch doesn't match. The vertical LED is the live input level (works even without recording, with Monitor on) — use it to confirm every mixer channel is really reaching the browser. Timeline: tap = move playhead · drag on ruler = loop region · drag on a track = selection (then Copy/Cut/Delete/Paste) · REC records from the playhead (punch-in) · W = warp to project BPM · Voice: say "rec" four times to start recording, "stop" four times to stop, "play" once to play.
